[Obsidian Trello](https://github.com/nathonius/obsidian-trello) is a community plugin for [Obsidian](https://obsidian.md) that connects Trello cards to notes, so you can see and update labels, comments, and checklists without leaving Obsidian. Cards are linked from a dedicated Trello pane, with a command to connect an existing card or create a new one directly from a note.

Trello data is cached locally rather than polled continuously, since Trello's REST API has strict rate limits, so cards can be manually refreshed if they fall out of sync. I'm a contributor to the project, maintained by [nathonius](https://github.com/nathonius).
